# Marang's Little World ♡

A cute interactive romantic microsite made with plain HTML, CSS and JavaScript.

## Open locally in VS Code

Use **Live Server** on `index.html`, or run:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Netlify

This is a static site. Drag the folder into Netlify Drop, or set the publish directory to the project root. No build step is required.

## Outsourced assets

Primary visual assets are hosted externally:

- Google Fonts: Cormorant Garamond, DM Sans, Great Vibes
- Iconify web component for UI icons
- OpenMoji SVGs for roses, sunflower, tulip and heart imagery
- Transparent Textures for paper grain

Local flower SVGs are only fallbacks for offline/dev previews when remote assets cannot be reached.
